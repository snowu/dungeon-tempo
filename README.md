# Dungeon Tempo
A rhythm roguelike about a dungeon band. Hit falling gems with D/F/J/K or touch to damage enemies. Misses and off-beat taps cost health. A run has five procedurally generated encounters, with a boss at the end. After each victory, choose one of three relics, then choose the standard crypt or a faster elite chamber. Elite wins heal 2 health. Relics modify damage, healing, maximum health, hit windows and shielding. Death resets the run; only your best score persists locally.

Each room has a four-beat count-in and a 36-beat time limit. Defeat the enemy before the music stops. Runs are generated from a random seed, shown beside the inventory. Patterns, enemies and relic offers are deterministic for that seed and route. Music changes its starting chord and tempo as you descend. Audio uses the Web Audio clock; pausing suspends that clock, and hiding the tab auto-pauses. Timing offset accommodates audio latency.

Run `npm run dev`, then open http://localhost:8087. Run timing tests with `npm test`. Deployable files are in `dist/`.

Art: **Kenney — Tiny Dungeon**, CC0, https://kenney.nl/assets/tiny-dungeon. Original license is included at `dist/assets/Kenney-License.txt`. The packed sprite sheet was obtained unchanged from the public mirror https://github.com/chaewonkong/tiny_dungeon/tree/main/assets/kenney_tiny-dungeon after the original download failed. Sprites were inspected before selecting the characters and wall tiles. Music is an original synthesized arrangement generated in game.js, with no external recording. Fonts are optional Google Fonts with system fallbacks.

Verification: `npm test` covers seeded generation, route tradeoffs, relic effects, damage, permadeath, a full five-room victory, UI reward/route transitions, scoring, pause and restart. Browser integration test: `node tests/browser.cjs` with a running local server and Playwright installed (or `PLAYWRIGHT_PATH`; optional `CHROME_PATH`). It plays all five rooms using real audio-clock timing, mixes keyboard and touch input, chooses an elite route, collects relics, defeats the boss, then verifies death and restart. Desktop and mobile screenshots are written to `/tmp/rogue-*.png`.
